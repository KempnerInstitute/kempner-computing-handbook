# Agentic Workflows in Practice

This chapter puts agents to work on common research tasks. Each page follows the same pattern: the task, what the agent does, the guardrails that keep it safe on a shared cluster, and how to check the result. {doc}`SLURM Jobs and Cluster Workflows <slurm_jobs_and_cluster_workflows>` covers writing, submitting, monitoring, and debugging jobs with an agent. {doc}`Experiment Management with Agents <experiment_management_with_agents>` builds on it with logging, sweeps, and checkpoints. {doc}`Working with Unfamiliar Research Codebases <unfamiliar_codebases>` uses [KempnerForge](https://github.com/KempnerInstitute/KempnerForge) to show how to get oriented in a new codebase, and {doc}`Refactoring Research Code into Packages <refactoring_into_packages>` covers turning scripts into a tested package without changing results. {doc}`Literature Review and Data Exploration <literature_review_and_data_exploration>` covers finding and checking sources and exploring datasets. {doc}`Multi-Agent Orchestration <multi_agent_orchestration>` covers chaining and coordinating several agents, and when one agent is the better choice.
